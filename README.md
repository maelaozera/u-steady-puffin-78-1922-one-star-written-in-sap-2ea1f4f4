Entry for the [One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4) bounty on make.fun.

## The entry

A single one-line, one-star review written by a houseplant about its human
owner — under 280 characters, with a real grievance at its centre. The plant
complains about being watered only when its owner's phone begs him to, being
dragged around the flat chasing better Wi-Fi, and having its dead leaves
dismissed as "character". The punchline plays the bounty theme literally: the
review is written in sap, because sap is the only ink a plant owns — and this
owner is not worth the good sap.

## How to run

Requires Node 22 or later (no dependencies to install):

```sh
node main.ts
```

This writes the review to `/output/entry.txt` and prints its character count.
The program self-checks the competition gate before writing: the entry must
be 1–279 characters, non-whitespace, on a single line.
